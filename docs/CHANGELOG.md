# CompixelUI 0.2.0

This release is for every supported Minecraft version: 1.20.1, 1.21.1, 26.1.2, 26.2 and 26.3. It includes breaking API and packaging changes from 0.1.x; mods built for 0.1.x need to update.

- Breaking: Compose now runs directly on Minecraft's client thread. Removed the separate UI thread, the deprecated `snapshot`, `handle` and `send` APIs, the state and action type parameters on screens and HUD layers, and the clipboard mailbox. Container slots are now read directly as they compose.
- Breaking: `gameState` is now a unified composable function (`dev.compixel.host.gameState`) callable directly inside `Content()` or any composable. It reads immediately on the game thread, refreshes on its tick interval and after `gameThread.post` work, and ends its subscription automatically when leaving the composition. See [Show game data](https://github.com/Frostbite-time/CompixelUI/blob/main/docs/en/getting-started.md#4-show-game-data).
- Breaking: removed the bundled Kotlin (`-with-kotlin` / `compixel-kotlin`) variant. CompixelUI now uses an external Kotlin runtime mod (Kotlin 2.2.21 or newer with compatible Coroutines and Serialization, such as Kotlin for Forge) without requiring a specific provider. If a compatible Kotlin runtime is missing or outdated, startup stops with a Forge/NeoForge error screen explaining what is needed.
- Changed: `compixel-runtime-standard` and `compixel-runtime-vulkan` (`1.3.0`) now nest independent third-party libraries via Jar-in-Jar with version negotiation ranges so other mods can share them cleanly, and publish separate non-transitive compile API and runtime-only variants via Gradle Module Metadata. Add `google()` to your build's `repositories` for the AndroidX compile dependencies, and supply standard Kotlin libraries (or a Kotlin runtime mod) when running `runClient`; see [Getting started](https://github.com/Frostbite-time/CompixelUI/blob/main/docs/en/getting-started.md) and [Compatibility](https://github.com/Frostbite-time/CompixelUI/blob/main/docs/en/compatibility.md).
- Added: [Minecraft resource images and fonts](https://github.com/Frostbite-time/CompixelUI/blob/main/docs/en/resources.md). `painterResource` loads raster textures from active resource packs as Compose `Painter`s, and `fontResource` loads TTF/OTF files as Compose `FontFamily`s; both follow Minecraft's resource pack priority and reload in place on F3+T without losing live UI state. Ore's bundled font is now served through `assets/compixel/font/compixel.ttf` so resource packs can replace it directly.
- Changed: replaced the fixed `guiUnitsPerDp` constructor parameter on `ComposeScreen`, `ComposeMenuScreen`, `ComposeInventoryScreen`, `ComposeHudLayer` and `UiLayer` with the overridable method `guiUnitsPerDp(framebufferWidth, framebufferHeight, guiScale)` (defaulting to `1f`), allowing screens and HUD layers to compute custom per-viewport scaling dynamically. Item icons rendered by `NativeItemAtlas` now rasterize at the layer's effective density rather than Minecraft's global GUI scale.
- Changed: CompixelUI now shares one Skia context per graphics device and warms up Compose, Ore controls, container slots, item glint, drag previews and tooltips directly on the client thread, reducing GPU overhead and first-open hitching.
